# Portfólio Profissional — V1

Base inicial de um portfólio profissional orientado a:

- desenvolvimento de sistemas;
- automação de processos;
- integrações;
- dados e Business Intelligence;
- apresentação de cases reais para recrutadores e pequenas empresas.

## Princípios

1. Não apresentar como concluído algo que ainda está em desenvolvimento.
2. Projetos devem demonstrar problemas resolvidos, não apenas tecnologias utilizadas.
3. Tecnologias entram como meio para a solução.
4. O portfólio deve funcionar para recrutadores e também para potenciais clientes.
5. Frameworks e dependências só devem ser adicionados quando houver justificativa técnica.

## Como executar

Não há dependências.

Opção mais simples:

1. abra a pasta;
2. abra `index.html` no navegador.

Para desenvolvimento, também pode ser utilizado o Live Server no VS Code.

## Pontos pendentes antes da publicação

- substituir links `#` por GitHub e LinkedIn reais;
- inserir nome profissional;
- revisar texto definitivo da seção Sobre;
- validar status e funcionalidades de cada projeto;
- adicionar screenshots reais;
- criar páginas individuais dos cases;
- configurar SEO social;
- testar Lighthouse;
- publicar no GitHub Pages ou Vercel.
